# ⚡ INSTALLATION COMMAND

## Required Command to Install Dependencies

Run this command in the `App` directory:

```bash
cd c:\Users\bhuwan.bhawarlal\Desktop\projects\TimeDrop\App
npm install react-native-maps-directions
```

---

## Alternative (If npm is not in PATH)

If you get an error that `npm` is not recognized, use the full path:

```bash
# Find your Node.js installation path, typically:
"C:\Program Files\nodejs\npm.cmd" install react-native-maps-directions
```

Or install using PowerShell:

```powershell
Set-Location c:\Users\bhuwan.bhawarlal\Desktop\projects\TimeDrop\App
& "C:\Program Files\nodejs\npm.cmd" install react-native-maps-directions
```

## If Installation Fails

### Error: "npm not recognized"
**Solution:** Use full path to npm as shown above, or install Node.js from https://nodejs.org/

### Error: "EACCES permission denied"
**Solution:** Run terminal/command prompt as Administrator

### Error: "Network timeout"
**Solution:** Check internet connection, try again or use:
```bash
npm install react-native-maps-directions --registry=https://registry.npmmirror.com
```
